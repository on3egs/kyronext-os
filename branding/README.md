# Identité originale Kyronext

Kyronext Systems — By Manix. Palette noire graphite, rouge et texte clair ; toutes les ressources vectorielles Kyronext de cette révision sont originales.

kyronext-mark.svg est l'emblème commun. Sa copie installée sous /usr/share/icons/Kyronext/scalable/apps/kyronext-logo.svg est utilisée par le menu. Une copie hicolor permet sa résolution depuis les applications qui ne suivent pas le thème d'icônes KDE.

Le thème d'icônes Kyronext hérite de Breeze Dark/Breeze/hicolor, dans cet ordre, et fournit des dessins originaux pour le logo, Dolphin, le terminal, les paramètres, les dossiers et le dossier personnel. FollowsColorScheme=true active la prise en compte de la palette KDE pour les symboles hérités, afin de conserver leur contraste sur les barres graphite. Les SVG Kyronext conservent leurs couleurs originales. Les icônes de composants non redessinés restent celles de Debian/KDE avec leurs licences d'origine.

Les créations Kyronext conservent le statut de licence indiqué dans LICENSES/README.md. Aucun logo, son, portrait, scanner ou média de série n'est utilisé. Le nom publié reste Kyronext OS. Le thème de démarrage et l'accueil sont gérés par leurs modules respectifs.
