# Mises à jour

Le Live utilise APT et les dépôts officiels Debian. Aucun dépôt de publication Kyronext indépendant ni application Kyronext Update n'est activé. Dans un Live non persistant, les changements ne survivent pas au redémarrage.

Une infrastructure de mises à jour Kyronext signées nécessitera sa propre conception et validation avant publication. Les signatures et mécanismes de sécurité APT ne sont pas désactivés.
