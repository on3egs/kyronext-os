# Essayer Kyronext OS

Cette édition est une préversion Live. Démarrer l'ISO dans une VM,
sans disque physique partagé, puis attendre le bureau KDE.

La session Kyronext s'ouvre automatiquement sans privilèges administrateur.
Le menu des applications donne accès à Dolphin (fichiers), Konsole (terminal)
et aux paramètres KDE. Les effets peuvent être désactivés dans les paramètres
du bureau. Le menu de session permet l'arrêt et le redémarrage.

Aucun installateur sur disque n'est inclus. Les changements de la session
Live sont temporaires. L'IA et le Cockpit ne sont pas disponibles en 0.1.
Consulter TEST_REPORT.md pour savoir ce qui a réellement été validé.
