# Dépendances

La liste de paquets explicites est dans iso/config/package-lists/.
APT résout les dépendances depuis Debian Trixie et ses mises à jour officielles.
Les versions exactes de l'image sont consignées dans packages.txt à la
fabrication. Les recommandations sont désactivées ; les composants utiles
du bureau sont donc ajoutés explicitement après vérification des candidats.
