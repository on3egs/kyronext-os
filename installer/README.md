# Installation future

Calamares est un candidat pour les versions suivantes. Aucun paquet Calamares ni installateur Debian actif n'est inclus dans la configuration 0.1. Une ISO Live n'est pas une ISO installable sur disque.

La prochaine expérimentation exigera un disque virtuel jetable, une identité de disque vérifiée, des tests de partitionnement et un protocole de retour arrière. Aucun essai d'installation sur disque physique n'est prévu ici.
