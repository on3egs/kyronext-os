# Applications

Le Live intègre Dolphin, Konsole et les paramètres KDE. L'accueil Kyronext est une petite application PyQt6. Les sources comprennent Kyronext Files, Settings, Monitor, AMP, Paint, Launchpad et d'autres outils à des niveaux de maturité différents. La candidate `releases/20261031T1854-suite-search-preview/` inclut `kyronext-suite-preview 0.1.0-0~preview2` et le lanceur Launchpad avec sa recherche locale facultative. Monitor a été ouvert visuellement dans QEMU UEFI ; l'interaction complète des autres apps reste à valider. La candidate propre antérieure `20261031T175731-clean-live` ne contenait pas le paquet. Kyronext Update a une première interface C++/Qt de consultation APT en simulation uniquement : elle ne rafraîchit pas les index et ne modifie aucun paquet. Kyronext Recovery produit un rapport local Linux en lecture seule. Ces composants de mise à jour/récupération ne sont pas intégrés à l'ISO. Center, Intelligence, Software et Security restent à développer ou compléter ; Studio dépend du projet existant. La présence d'un composant source ne prouve pas qu'il est empaqueté ou prêt pour l'utilisateur.

Les programmes Kyronext existants n'ont pas été modifiés ni copiés dans l'image. Leur intégration nécessitera une vérification des dépendances Linux, des ressources et des licences.
