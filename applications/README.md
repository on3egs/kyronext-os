# Applications

Le Live intègre Dolphin, Konsole et les paramètres KDE. L'accueil Kyronext est une petite application PyQt6. Les applications indépendantes Center, Files, Settings, Intelligence, Software, Update, Security et Studio ne sont pas encore développées.

Les programmes Kyronext existants n'ont pas été modifiés ni copiés dans l'image. Leur intégration nécessitera une vérification des dépendances Linux, des ressources et des licences.
