# Licences et redistribution

Les composants Debian conservent leurs licences ; consulter /usr/share/doc/*/copyright et le manifeste packages.txt de chaque image.

Le dépôt non-free-firmware officiel fournit des micrologiciels binaires redistribués par Debian. Ce ne sont pas tous des logiciels libres. Leur présence et leurs licences doivent être relevées dans le manifeste final. Aucun pilote Windows ou ancien installateur NVIDIA propriétaire n'est ajouté.

Les sources et créations originales Kyronext sont réservées à Kyronext Systems — By Manix dans l'attente du choix de licence du propriétaire. La veille contient des illustrations originales évocatrices des voitures KITT et KARR, sans copie de photogramme, logo officiel, voix ou musique de la série. Ces créations ne confèrent aucun droit sur les éléments de tiers ; leurs limites de redistribution sont décrites dans [VEILLE.md](VEILLE.md). Le nom officiel publié reste Kyronext OS.

## Navigateur et applications Qt

Firefox ESR est le paquet officiel Debian `firefox-esr`, sous les licences
Mozilla indiquées dans `/usr/share/doc/firefox-esr/copyright`. Le profil et le
CSS Kyronext sont des ajouts séparés ; ils ne sont ni une édition Firefox ni une
approbation de Mozilla.

Kyronext Navigator est compilé avec Qt WebEngine provenant de Debian Trixie.
Qt WebEngine et Chromium incorporent plusieurs composants tiers : leurs notices
et licences livrées par les paquets Debian sont conservées dans
`/usr/share/doc/qt6-webengine*/copyright` et les paquets associés. L'intégration
reste expérimentale et requiert les mises à jour de sécurité Debian. Aucune
copie de marque, d'icône ou de code propriétaire de Firefox n'est utilisée.
